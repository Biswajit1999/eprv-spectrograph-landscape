# Contributing

Contributions are welcome when they improve traceability rather than add
unsupported breadth.

For a new instrument or updated status:

1. Add a primary instrument/performance reference and a dated official
   facility or consortium status source.
2. Classify the performance evidence using `docs/METHODS.md`.
3. Do not translate heterogeneous prose into a universal precision score.
4. Run `pytest -q`, `ruff check src tests`, and `eprv-landscape build`.
5. Explain any changed source value and access date in `CHANGELOG.md`.

Corrections to specifications, source interpretation, accessibility, and
plot clarity are especially useful.
